# AAマスター

AAオークション会場の開催曜日・通常セリ落札とワンプライス落札の搬出期限を学ぶ、スマホ対応の学習サイトです。

**サイト:** https://xiangdo0910.github.io/route-master-public/aa-master/

- 全国の主要AA会場（初期57会場）を検索
- 開催曜日・搬出期限のクイズ、復習
- 会場ルールの手動編集、バックアップ
- 学習状況はブラウザ内のlocalStorageに保存（端末間同期なし）

## 注意
公開されたルールに基づく学習用の試作版です。未確認の搬出期限は正解扱いせず、祝日やコーナーごとの例外にも対応しません。実務では最新の会場公式規約および車両ごとの搬出案内をご確認ください。

このフォルダは航路マスターと独立したWebページです。リポジトリのルートの `index.html`（航路マスター）は変更していません。
